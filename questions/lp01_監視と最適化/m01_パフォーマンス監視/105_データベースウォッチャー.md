# 監視105 — データベース ウォッチャー

> 対応ユニット: [データベース ウォッチャーについて説明する](https://learn.microsoft.com/ja-jp/training/modules/describe-performance-monitoring/6-describe-database-watcher)

## 問題 1

Database Watcher が監視対象としてサポートするサービスはどれですか？（2 つ選択）

- A. Azure SQL Database
- B. SQL Server on Azure VM（IaaS）
- C. Azure SQL Managed Instance
- D. Azure Cosmos DB for NoSQL

<details>
<summary>解答・解説</summary>

**解答:** A、C

Database Watcher は Azure SQL Database と Azure SQL Managed Instance 専用に設計された監視ソリューションです。IaaS 上の SQL Server や Cosmos DB は対象外です。

| 選択肢 | 説明 | 正否 |
|---|---|---|
| A. Azure SQL Database | Database Watcher のサポート対象 | ✅ 正解 |
| B. SQL Server on Azure VM | IaaS は対象外 | ❌ |
| C. Azure SQL Managed Instance | Database Watcher のサポート対象 | ✅ 正解 |
| D. Azure Cosmos DB for NoSQL | 対象外 | ❌ |

</details>

## 問題 2

Database Watcher が収集した監視データを格納・分析するためのデータ ストアとして選択できるものはどれですか？（2 つ選択）

- A. Azure SQL Database
- B. Azure Data Explorer（無料クラスター含む）
- C. Azure Blob Storage
- D. Microsoft Fabric の Real-Time Analytics データベース

<details>
<summary>解答・解説</summary>

**解答:** B、D

Database Watcher はデータ ストアとして Azure Data Explorer クラスター（無料クラスターも可）または Microsoft Fabric の Real-Time Analytics データベースを使用できます。どちらも時系列データの取り込みと分析に最適化されています。

| 選択肢 | 説明 | 正否 |
|---|---|---|
| A. Azure SQL Database | Database Watcher のデータ ストアとして選択できない | ❌ |
| B. Azure Data Explorer | 選択可能なデータ ストア | ✅ 正解 |
| C. Azure Blob Storage | データ ストアとして選択できない | ❌ |
| D. Microsoft Fabric Real-Time Analytics | 選択可能なデータ ストア | ✅ 正解 |

</details>

## 問題 3

Database Watcher の主な利点として正しいものはどれですか？

- A. SQL Server の実行クエリをリアルタイムでキャンセルできる
- B. サブスクリプション内の中央データ ストアに監視データを収集し、数秒以内にデータを取り込める
- C. SQL Server の自動パッチ適用を管理できる
- D. 拡張イベント セッションを GUI なしで管理できる

<details>
<summary>解答・解説</summary>

**解答:** B

Database Watcher の主な機能は、Azure サブスクリプション内の中央データ ストアに監視データを収集・格納できることです。データの収集とインジェストは数秒以内に行われ、低遅延でリアルタイムに近い監視が可能です。

| 選択肢 | 説明 | 正否 |
|---|---|---|
| A. クエリのキャンセル | Database Watcher の機能ではない | ❌ |
| B. 中央データ ストアへの低遅延収集 | Database Watcher の主な利点 | ✅ 正解 |
| C. 自動パッチ適用の管理 | SQL IaaS エージェント拡張機能の機能 | ❌ |
| D. 拡張イベントの GUI なし管理 | Database Watcher の機能ではない | ❌ |

</details>

## 問題 4

Database Watcher を Azure Portal で作成する際に設定が必要なものはどれですか？（2 つ選択）

- A. データ ストアの構成（Azure Data Explorer または Microsoft Fabric）
- B. SQL Server の sa パスワード
- C. 監視する SQL ターゲット（Azure SQL Database / Managed Instance）の選択
- D. 拡張イベント セッション名

<details>
<summary>解答・解説</summary>

**解答:** A、C

Database Watcher の作成時には、監視データを格納するデータ ストア（Azure Data Explorer または Microsoft Fabric）の設定と、監視対象の SQL ターゲットの選択が必要です。

| 選択肢 | 説明 | 正否 |
|---|---|---|
| A. データ ストアの構成 | 必須設定 | ✅ 正解 |
| B. sa パスワード | Database Watcher の設定項目ではない | ❌ |
| C. SQL ターゲットの選択 | 必須設定 | ✅ 正解 |
| D. 拡張イベント セッション名 | Database Watcher は拡張イベントとは独立した機能 | ❌ |

</details>
